# Chassis extension layer

Additional 3D printed mounting layer for the TI-RSLK MAX chassis, carrying the Arduino Uno and the
breadboard above the chassis board.

Commit both the editable source file (`.f3d`, `.step` or equivalent) and the exported `.stl`. The
STL alone cannot be edited by anyone who needs to change the part.
