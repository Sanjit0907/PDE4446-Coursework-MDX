# Ultrasonic sensor mount

3D printed bracket holding the HC-SR04 at the front of the robot, facing straight ahead at a fixed
height.

Commit both the editable source file and the exported `.stl`.

| File | Description |
|---|---|
| | |

Measured once fitted - these two numbers are used by the avoidance calculations and must be
recorded here:

| Measurement | Value |
|---|---|
| Sensor face height above the floor | mm |
| Sensor face to the wheel axle | mm |
| Sensor face to the rear-most point of the robot | mm |
